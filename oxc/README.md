# OXC Demo

Demo project to verify [oxfmt](https://oxc.rs/docs/guide/usage/formatter.html) (formatter) and [oxlint](https://oxc.rs/docs/guide/usage/linter.html) (linter) from the OXC toolchain.

## Usage

```bash
pnpm lint
```

This runs:

1. `oxfmt` - Format TypeScript files
2. `oxlint` - Lint TypeScript files
